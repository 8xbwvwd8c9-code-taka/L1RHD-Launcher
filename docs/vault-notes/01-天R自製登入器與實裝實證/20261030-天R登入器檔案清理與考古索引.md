## 5. 重建指引（沒有現成 exe 之後）

1. **加 Defender 排除**（先做，否則重建後執行即被隔離）：`G:\L1RHD\`、`I:\RHD\RHDLauncher-rs\target\`。
2. **建置**：`cd I:\RHD\RHDLauncher-rs` → `cargo build --release`（Rust；`target/` 已清空，需重新拉依賴）。
3. **補丁 DLL**：`rhd_inproc.dll` 仍在 `G:\L1RHD\`，直接沿用（八刀站點未變）。
4. **設定**：`G:\L1RHD\launcher.json` 需含下列鍵值——
   `inproc_launch=true`、`proxy_login=true`、`login_account=5566`、`login_password=5566`、`inject_s_key=true`、`packet_capture=true`。
5. **服務端**：`X:\L1RHD\L1RHDserver`，JDK8 啟動
   `java -Xms1g -Xmx8g -Dsun.stdout.encoding=UTF-8 -Dlog4j.configuration=file:config/log4j.properties -jar gs.jar`（`gs.jar` 仍是 `8C8707FE…`）。
6. **埠拓撲**：客戶端 → 中繼 `2000`／`29467` → `127.0.0.1:3000`。
7. **驗收判準**：中繼日誌出現「補發 S_KEY」→ `C>S 161`→`S>C 90`→`C>S 295`→「opcode 199 已改寫」→`S>C 32/194`；服務端 console 出現 `玩家=1` 與 `測試1 進入遊戲帳號==5566`。
