# 天R登入器成功登入流程固化（SOP）

## 0. 這份文件的定位

把「RHDLauncher（B4）→ 中繼補發 S_KEY → 明文帳密 → 進入世界」的**可重跑流程**固定下來。
本 SOP 於 2026-10-30 21:53–21:57 依此流程完整複驗通過（第二次進世界）。
證據與推論見 [[20261030-天R登入器B4中繼補發S_KEY與進入世界實證]]；檔案處置見 [[20261030-天R登入器檔案清理與考古索引]]。

> [!IMPORTANT] 三個不可省的條件
> 1. `G:\L1RHD` 與 `I:\RHD\RHDLauncher-rs` **必須在 Defender 排除名單**，否則執行後數分鐘內 exe 會被 `Behavior:Win32/DefenseEvasion.A!ml` 隔離（2026-10-30 21:22 已發生一次）。
> 2. 服務端依 ADR-005 **永久停發 S_KEY**；S_KEY 只能由**中繼往客戶端方向補發**，不可改回服務端發送。
> 3. `launcher.json` 的 `inproc_launch`、`proxy_login`、`inject_s_key` 三個旗標必須同時為 `true`。

## 2. 設定檔（`G:\L1RHD\launcher.json`）

```json
{
  "direct_launch": true,
  "inproc_launch": true,
  "packet_capture": true,
  "proxy_login": true,
  "login_account": "<帳號>",
  "login_password": "<密碼>",
  "inject_s_key": true,
  "patch_grace_secs": 2,
  "minimize_to_tray": true,
  "block_official_list": true,
  "update_manifest_url": "",
  "update_strict": false
}
```

`update_manifest_url`（2026-10-31 新增）：**自動吃檔** manifest URL（`Login.local` 同格式：`[相對路徑]`＋`md5=<hex>`），留空＝停用；每次進入遊戲前自動拉清單→MD5 比對→下載差異→驗證套用（資源取自 manifest 同目錄樹）。`update_strict=true`＝吃檔失敗中止啟動（預設 false 只記錄）。詳見 [[20261031-天R登入器B4當機採證與歐霸天堂Login.exe反編譯取證]] §2.4／§2.5。

`servers.ini` 的 listen 埠需涵蓋 `2000,29467`，`host=127.0.0.1`、`port=3000`。

## 3. 啟動（一鍵）

```powershell
Start-Process 'G:\L1RHD\RHDLauncher-B4-skkey.exe' -WorkingDirectory 'G:\L1RHD' -Verb RunAs
```

- 必須以**管理員**身分啟動（客戶端 `requireAdministrator`＋八刀寫入需求）。
- 登入器會自行：建立中繼 → 掛起啟動 `Lin.bin` → 注入 `rhd_inproc.dll` → 寫八刀 → 交棒常駐中繼 `daemon` → 主進程退出（正常行為，不是崩潰）。

## 7. 重建（exe 不見時）

> [!CAUTION] 2026-10-31 CFA 閘門
> `I:\RHD` 與 `G:\L1RHD` 已被 Defender **受控資料夾存取權（CFA）**保護（`EnableControlledFolderAccess=1`）：非白名單程式（bash/cp/cmd/pwsh 等）寫入一律被拒，**提權也不解鎖**（CFA 是 app 級）。事件 1123 為證。因此：原位重建需先把 `cargo.exe`/`rustc.exe`/`git.exe` 加入 `ControlledFolderAccessAllowedApplications`（管理員 PowerShell），或改在未保護的克隆（現行＝`G:\RHDLauncher-rs-build`）建置。部署 exe 需先白名單 `powershell.exe`，見 [[20261031-天R登入器B4當機採證與歐霸天堂Login.exe反編譯取證]] §3.1-5。

```powershell
Set-Location 'G:\RHDLauncher-rs-build'      # 2026-10-31 起的建置克隆（含 B4+ commit 2ee5f5d）
cargo build --release
Copy-Item 'target\release\rhd-launcher.exe' 'G:\L1RHD\RHDLauncher-B4-skkey.exe' -Force
```

- 2026-10-31 改進版（`2ee5f5d`，BUILD_TAG `20261031-heartbeat1`）：15,821,312 B，SHA-256 `9E4A7A8A557040BD2CE5A4E66DA594E2B641EB26719387F81EDB8D88EC01DC5D`；新增 build 標記、啟動期凍結風險掃描、daemon/補丁等待雙心跳（10 秒）。
