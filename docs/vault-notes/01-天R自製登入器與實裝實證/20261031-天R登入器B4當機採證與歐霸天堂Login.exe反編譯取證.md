### 2.5 RHDLauncher 吃檔／自動更新實作（同日完成，commit `dd2e3ad`）

以 `Login.local` 同格式**純文字 manifest** 取代官方 protobuf 對帳（私服自管兩端，無需 protobuf），流程同構 NCTinyUpdater：

1. `launcher.json` 設 `"update_manifest_url": "http://<私服>/patch/manifest.local"`（**留空＝停用**）。
2. 按「進入遊戲」時（`boot_sequence` 背景執行緒、`launch_inproc` 之前）：拉 manifest → 逐檔 MD5 比對（不動／變更／缺檔）→ 僅下載差異 → **下載後 MD5 複驗** → 暫存檔改名就地套用。
3. 資源 URL＝manifest 所在目錄＋manifest 內相對路徑（`data\x.tbl` → `<目錄>/data/x.tbl`）；**不改寫客戶端 `Login.local` 本體**（那是 Login.exe 自己的契約）。
4. 安全：防路徑穿越（拒 `..`／磁碟號／絕對路徑）、單檔 512 MiB／整輪 4 GiB／5000 條上限、MD5 大小寫正規化。
5. `update_strict=true`＝吃檔失敗中止啟動；預設 `false`（記錄後照常啟動）。
6. **伺服端只需靜態檔案服務**：manifest 檔＋同目錄樹的資源檔（任何 HTTP server 均可，含 `python -m http.server`）。

驗證：`cargo test` **27/27**（含 std TcpListener 本地 HTTP **端到端**：拉清單→比對→下載→驗證→套用全鏈）；release `64F47728…`（16,067,072 B）已部署 `G:\L1RHD`。
