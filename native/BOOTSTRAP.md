# 自製啟動模組：載入探針

此階段只驗證自製 DLL 可由 Microsoft Detours 載入自製測試程式。DLL 不等待、不建立執行緒、不初始化遊戲、不寫入客戶端程式碼。

`rhd_probe` 只接受四種固定測試情境。它從自身目錄找 `rhd_fixture.exe`，先核對編譯時生成的 SHA-256，並在建立程序前持續持有唯讀檔案控制代碼。它沒有接收任意執行檔路徑的介面。

需要 Windows x64、CMake 和 MSVC C++ 工具鏈。在此目錄執行：

```powershell
.\build.ps1 -BuildDir <建置產物目錄>
```

建置使用本目錄中固定版本的 Detours 原始碼壓縮檔，不需要建置時下載。CMake 核對壓縮檔 SHA-256；MIT 授權見 `LICENSE.Detours.txt`。自製 DLL 的載入結果只代表測試程式的結果，不代表遊戲相容或不會當機。

正式遊戲啟動仍停用。需要先證明同步點及所有初始化目標的安全條件，才能另行接入。

`rhd_transaction_fixture` 是獨立的測試執行檔，只操作自己用 `VirtualAlloc` 配置的兩頁記憶體；它不接受程序或檔案路徑，也沒有連入啟動器或 DLL。測試涵蓋同步條件、版本、所有原值、範圍與重疊檢查，並模擬頁面保護失敗、保護競態、部分寫入、指令快取失敗、保護還原失敗及回復失敗。回復失敗時必須報告不安全狀態，不得繼續執行。

測試頁面無其他讀寫或執行緒：這個人工條件不能證明真實遊戲的同步點或保護驅動相容。實際遊戲的初始化仍未實作，驗收仍為 OPEN。
